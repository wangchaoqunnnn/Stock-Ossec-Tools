# Stock-Ossec-Tools（老王量化 - 个股查询工具 自建版）

> 参考 [https://stock.ossec.cn/tools](https://stock.ossec.cn/tools)（老王量化）实现的股票数据查询工具网页。
> 本项目的定位是：**免登录、免VIP、免投票、纯只读展示**的股票行情查询工具。

---

## 一、需求文档

### 1. 项目背景

参考网站「老王量化」的 **个股查询** 工具页（`/tools`），该页面提供股票查询、主要指数行情、关注清单三大核心能力。
本项目参考其页面结构与信息呈现方式，自建一套无需账号体系、无需付费订阅、无社区互动的精简版股票数据查询工具。

### 2. 项目目标

- 提供一个可直接访问的网页，展示 A 股/港股/美股主要指数行情与个股行情。
- 支持按股票代码或名称快速检索个股，并展示完整行情详情。
- 提供一份「关注清单」表格，实时展示预置股票池的行情数据，支持排序与分页。
- 全部数据来源于公开行情接口（东方财富），无任何账号、权限、付费门槛。

### 3. 功能需求

#### 3.1 个股查询
- 提供搜索输入框，支持按 **股票代码**（如 `600000`）或 **名称关键词**（如 `浦发`）模糊检索。
- 检索结果以下拉列表展示（代码 + 名称 + 市场类型），点击或回车后展示该股票的行情详情。
- 行情详情字段：现价、涨跌额、涨跌幅、今开、最高、最低、昨收、成交量（手）、成交额（元）、换手率、量比、市盈率(TTM)、市净率、总市值、流通市值、振幅、行业。

#### 3.2 主要指数
- 指数卡片式展示，支持 **A股 / 港股 / 美股** 三个市场切换。
- 每个指数展示：名称、当前点位、涨跌额、涨跌幅。
- 指数范围：
  - A股：上证指数、深证成指、沪深300、创业板指、科创50、北证50
  - 港股：恒生指数、恒生科技、国企指数
  - 美股：道琼斯、纳斯达克、标普500

#### 3.3 关注清单
- 只读表格展示预置股票池的实时行情，字段：代码、名称、现价、涨跌幅、涨速、今开、最高、最低、昨收、换手率、量比、市盈率、市净率、总市值、流通市值、行业。
- 支持按字段 **升序/降序排序**、**分页**（每页 10/15/20/50 条）。
- 股票池由后端配置文件维护（`backend/data/watch_list.json`），无需用户操作。

#### 3.4 明确排除的功能（不做）
| 排除项 | 说明 |
| --- | --- |
| 注册 / 登录 | 无任何账号体系，打开即用 |
| VIP / 付费订阅 | 所有功能对所有人开放，无权限分级、无隐藏字段 |
| 投票功能 | 无任何投票、点赞、评选 |
| 交互功能 | 无评论、发帖、关注操作、自选股管理、模拟交易、消息通知等一切写操作 |
| 社区 / 社交 | 无社区、私信、排行榜等用户生成内容 |

### 4. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 运行环境 | 后端：Python **3.8+**（Flask）；前端：Vue 3 + Ant Design Vue |
| 兼容性 | 后端代码使用 Python 3.8 兼容语法（无 `match`、无 `|` 类型联合等 3.9+ 特性） |
| 响应速度 | 行情数据带 10 秒 TTL 缓存，避免高频请求上游接口 |
| 稳定性 | 上游接口异常时返回友好错误信息，页面不崩溃 |
| 前端体验 | 暗色终端风格，与参考站保持一致；桌面/移动端自适应 |
| 部署 | 单进程即可运行：后端同时托管 API 与前端静态资源 |
| 安全 | 无用户输入写入、无敏感数据；后端仅做数据聚合转发 |
| 合规 | 数据来源于公开行情接口，仅用于学习与个人参考，不构成投资建议 |

### 5. 技术架构

```
浏览器 (Vue3 + Ant Design Vue, Vite 构建)
        │  HTTP /api/*
        ▼
Flask 后端 (Python 3.8)
   ├── /api/indices         主要指数行情
   ├── /api/stock/search    股票检索
   ├── /api/stock/quote     个股行情详情
   └── /api/watch/list      关注清单行情
        │  短缓存 (TTL 10s) + 主备双数据源自动切换
        ▼
主源：东方财富公开行情 (push2.eastmoney.com / searchapi / codetable)
备源：腾讯行情 (qt.gtimg.cn) —— 东财不可达时自动回退
```

- 前端通过 Vite 开发代理（`/api` → `:5000`）或同源部署访问后端。
- 后端对所有上游请求做 10 秒内存缓存，控制外部依赖频率。
- 双数据源：默认请求东方财富（字段更丰富，含行业、涨速）；东财接口异常时自动回退腾讯行情，保证页面始终可用。各接口响应中带 `source` 字段（`eastmoney` / `tencent`）标识实际数据来源。

### 6. 接口定义（REST）

| 方法 | 路径 | 参数 | 说明 |
| --- | --- | --- | --- |
| GET | `/api/health` | - | 健康检查 |
| GET | `/api/indices` | `market=cn\|hk\|us`（默认 cn） | 主要指数行情 |
| GET | `/api/stock/search` | `keyword=关键词&count=8` | 股票模糊检索 |
| GET | `/api/stock/quote` | `code=600000` | 个股行情详情 |
| GET | `/api/watch/list` | `sort=zdf&order=desc&page=1&page_size=15` | 关注清单（实时行情 + 分页排序） |

响应统一格式：`{"code": 0, "message": "ok", "data": {...}}`。

### 7. 数据来源与免责声明

- 行情数据来自东方财富公开接口，仅作个人学习与技术演示用途，数据可能存在延迟或误差。
- 本项目不构成任何投资建议，据此操作风险自负。

## 三、运行说明

### 1. 后端（Python 3.8+）

```bash
cd backend
pip install -r ../requirements.txt   # 或 pip install Flask==2.3.3 flask-cors==3.0.10 requests==2.31.0
python app.py                         # 默认监听 0.0.0.0:5000
```

验证：浏览器访问 `http://127.0.0.1:5000/api/health` 返回 `{"code":0,...}` 即成功。

### 2. 前端（开发模式）

```bash
cd frontend
npm install
npm run dev                          # 默认 http://localhost:5173，/api 代理到 :5000
```

### 3. 生产部署（单进程）

```bash
cd frontend && npm install && npm run build   # 产物输出到 frontend/dist
cd ../backend && python app.py                # 后端自动托管 frontend/dist 静态页面
```

访问 `http://127.0.0.1:5000/` 即为完整页面（API 与页面同源）。
