# Stock-Ossec-Tools（老王量化 - 自建版）

> 参考 [https://stock.ossec.cn](https://stock.ossec.cn)（老王量化）主站实现的股票数据查询工具网页。
> 本项目的定位是：**免登录、免VIP、免投票、纯只读展示**的股票行情查询与分析工具。

---

## 一、需求文档

### 1. 项目背景

参考网站「老王量化」主站（`stock.ossec.cn`），该网站提供个股查询、投资组合、量化工具、行情中枢、复盘社区等多个模块。
本项目参考其页面结构与信息呈现方式，自建一套无需账号体系、无需付费订阅、无社区互动的精简版股票数据查询与分析工具。

### 2. 项目目标

- 提供一个可直接访问的网页，展示 A 股/亚太/美股/期货主要指数行情与个股行情。
- 支持按股票代码或名称快速检索个股，并展示完整行情详情与多维度分析。
- 提供投资组合、量化工具、行情中枢、复盘社区等辅助分析模块。
- 全部数据来源于公开行情接口（东方财富 / 腾讯），无任何账号、权限、付费门槛。

### 3. 功能需求

#### 3.1 首页（Home）
- 欢迎区：展示网站名称、简介与快速入口。
- 指数速览：展示主要指数实时行情卡片。
- 功能入口：提供个股查询、投资组合、量化工具、行情中枢、复盘社区五个模块的快捷入口。

#### 3.2 个股查询（Tools）
- 提供搜索输入框，支持按 **股票代码**（如 `600000`）或 **名称关键词**（如 `浦发`）模糊检索。
- 检索结果以下拉列表展示（代码 + 名称 + 市场类型），点击或回车后展示该股票的行情详情。
- 行情详情字段：现价、涨跌额、涨跌幅、今开、最高、最低、昨收、成交量（手）、成交额（元）、换手率、量比、市盈率(TTM)、市净率、总市值、流通市值、振幅。
- 支持科创板、创业板股票搜索。
- **详情弹窗**（真实交易数据，点击"详情"打开，三个标签页）：
  - **行情走势**：真实前复权 K 线（分时/日K/周K/月K 可切换，来源于腾讯行情接口）。
  - **技术指标**：基于真实 K 线计算的 MACD / KDJ / RSI / BOLL / MA5/10/20/60。
  - **基本面**：真实现价、涨跌幅、换手率、量比、市盈率(TTM)、市净率、总市值、流通市值、振幅、今开/最高/最低/昨收、成交量/成交额。
- 个股行情与详情弹窗每 15 秒自动刷新。

#### 3.3 主要指数
- 指数卡片式展示，支持 **A股 / 亚太 / 美股 / 期货** 四个市场切换。
- 每个指数展示：名称、当前点位、涨跌额、涨跌幅。
- 开启"自动"开关后每 **15 秒**自动刷新，页面从后台切回时立即刷新。
- 指数范围：
  - A股：上证指数、深证成指、沪深300、创业板指、科创50、北证50
  - 亚太：恒生指数、恒生科技、国企指数、日经225、韩国KOSPI、澳洲ASX200、台湾加权
  - 美股：道琼斯、纳斯达克100、标普500
  - 期货：沪深300股指、上证50股指、中证500股指、中证1000股指、黄金期货、原油期货

#### 3.4 关注清单（Watchlist）
- 支持添加/删除关注股票，数据本地存储（localStorage）。
- 支持9列可配置展示：代码、名称、现价、涨跌幅、涨速、成交额、信号、备注、操作。
- 支持多维度排序（关注日期/现价/涨跌幅等）。
- 支持备注编辑。
- 支持批量添加股票。
- 支持每 30 秒自动刷新行情，页面从后台切回时立即刷新。

#### 3.5 投资组合（Portfolio）
- **自选组合**：以真实涨幅榜为持仓样例展示实时行情（代码/名称/现价/涨跌幅/换手率/成交额/行业）。
- **策略分类**：公开组合的策略分布与收益统计需接入组合数据源后提供（当前为占位态）。

#### 3.6 量化工具（Utility）
- **今日关注**：实时涨幅榜（沪深京 A 股，代码/名称/现价/涨跌幅/换手率/成交额/行业），支持按代码/名称筛选，每 15 秒自动刷新。
- **选股器 / 异动寻龙**：依赖量化信号与暗盘/明盘资金等专用数据源，暂以占位态展示，待接入后提供真实结果。

#### 3.7 行情中枢（Rankings）
- **市场情绪**：实时市场涨跌家数分布（上涨/平盘/下跌家数、涨停/跌停家数、上涨占比）+ 分档涨跌分布柱状图。
- **资金流向**：行业板块主力资金净流入排名（净流入金额、净占比、涨跌幅）。
- **榜单**：涨幅榜 / 跌幅榜 / 成交额榜 / 换手率榜（沪深京 A 股）。
- 数据每 15 秒自动刷新，页面切回立即刷新；上游间歇性不可达时优雅降级为提示态。

#### 3.8 复盘社区（Community）
- 精选复盘文章为静态示例内容（编辑性内容，非行情数据），仅供参考。

#### 3.9 明确排除的功能（不做）
| 排除项 | 说明 |
| --- | --- |
| 注册 / 登录 | 无任何账号体系，打开即用 |
| VIP / 付费订阅 | 所有功能对所有人开放，无权限分级、无隐藏字段 |
| 投票功能 | 无任何投票、点赞、评选 |
| 用户留言 / 交互 | 无评论、发帖、关注操作、模拟交易、消息通知等一切用户写操作 |
| 社区 / 社交 | 无用户生成内容，复盘社区为静态文章展示 |

### 4. 非功能需求

| 类别 | 要求 |
| --- | --- |
| 运行环境 | 后端：Python **3.8+**（Flask）；前端：Vue 3 + Ant Design Vue + Vite |
| 兼容性 | 后端代码使用 Python 3.8 兼容语法（无 `match`、无 `|` 类型联合等 3.9+ 特性） |
| 响应速度 | 行情数据带 10 秒 TTL 缓存，避免高频请求上游接口 |
| 数据实时性 | 首页指数速览、主要指数、个股行情详情每 15 秒自动刷新；关注清单每 30 秒刷新；页面从后台切回时立即刷新。上游缓存 10s，故实际数据滞后不超过约 10 秒 |
| 稳定性 | 上游接口异常时返回友好错误信息，页面不崩溃 |
| 前端体验 | 暗色终端风格，与参考站保持一致；桌面/移动端自适应 |
| 部署 | 单进程即可运行：后端同时托管 API 与前端静态资源 |
| 安全 | 无用户输入写入、无敏感数据；后端仅做数据聚合转发 |
| 合规 | 数据来源于公开行情接口，仅用于学习与个人参考，不构成投资建议 |

### 5. 技术架构

```
浏览器 (Vue3 + Ant Design Vue, Vite 构建)
        │  HTTP /api/*
        ▼
Flask 后端 (Python 3.8)
   ├── /api/health          健康检查
   ├── /api/indices         主要指数行情（A股/亚太/美股/期货）
   ├── /api/stock/search    股票检索（支持科创板/创业板）
   ├── /api/stock/quote     个股行情详情
   ├── /api/stock/batch     批量行情查询
   ├── /api/rankings/market-breadth  市场涨跌分布
   ├── /api/rankings/industry-flow   行业资金流向
   └── /api/rankings/top             股票榜单（涨/跌/成交额/换手）
        │  短缓存 (TTL 10s) + 主备双数据源并发请求（谁先成功用谁，主源优先）
        ▼
主源：东方财富公开行情 (push2.eastmoney.com / push2ex / searchapi / codetable)
备源：腾讯行情 (qt.gtimg.cn) —— 东财挂起/失败时快速兜底（行情中枢榜单类接口无腾讯回退，失败时优雅降级）
```

- 前端通过 Vite 开发代理（`/api` → `:5000`）或同源部署访问后端。
- 后端对所有上游请求做 10 秒内存缓存，控制外部依赖频率。
- 双数据源：**主备并发请求**，东方财富与腾讯同时发起，优先取主源成功结果；
  东财挂起（连接超时）或失败时自动采用腾讯结果，避免用户长时间等待（实测主源不可达时
  响应约 0.6~0.9s，而串行重试需 4~5s）。各接口响应中带 `source` 字段
  （`eastmoney` / `tencent`）标识实际数据来源。
- 指数定义采用配置驱动：`config.INDICES` 中每个指数同时标注东财 secid 与腾讯代码，
  回退时按条目精确映射，避免市场间数据错位。
- K 线、分时、技术指标使用腾讯行情接口（`web.ifzq.gtimg.cn`），稳定可靠；行业资金流向、
  榜单、涨跌分布使用东方财富公开接口（间歇性可达，失败时优雅降级）。

### 6. 接口定义（REST）

| 方法 | 路径 | 参数 | 说明 |
| --- | --- | --- | --- |
| GET | `/api/health` | - | 健康检查 |
| GET | `/api/indices` | `market=cn\|asia\|us\|futures`（默认 cn） | 主要指数行情 |
| GET | `/api/stock/search` | `keyword=关键词&count=8` | 股票模糊检索 |
| GET | `/api/stock/quote` | `code=600000` | 个股行情详情 |
| GET | `/api/stock/kline` | `code=600000&period=day\|week\|month&count=120` | 前复权 K 线（真实） |
| GET | `/api/stock/minute` | `code=600000` | 当日分时明细（真实） |
| GET | `/api/stock/indicators` | `code=600000&period=day` | 技术指标（MACD/KDJ/RSI/BOLL/MA，基于真实 K 线计算） |
| GET | `/api/stock/batch` | `codes=600000,000001` | 批量行情查询 |
| GET | `/api/rankings/market-breadth` | - | 市场涨跌家数分布 |
| GET | `/api/rankings/industry-flow` | `limit=20` | 行业主力资金净流入排名 |
| GET | `/api/rankings/top` | `type=gainers\|losers\|amount\|turnover&limit=20` | 股票榜单 |

响应统一格式：`{"code": 0, "message": "ok", "data": {...}}`。

### 7. 数据来源与免责声明

- 行情、K 线、分时、技术指标、涨跌分布、榜单、行业资金流向等均来自东方财富 / 腾讯公开接口，仅作个人学习与技术演示用途，数据可能存在延迟或误差。
- 财务数据（营收/利润/ROE）、资金流向、机构评级、暗盘资金、异动、公开组合等需接入专用数据源，当前不展示或为占位态。
- 本项目不构成任何投资建议，据此操作风险自负。

## 三、运行说明

### 1. 后端（Python 3.8+）

```bash
cd backend
pip install -r ../requirements.txt   # 或 pip install Flask==2.3.3 flask-cors==3.0.10 requests==2.31.0
python app.py                         # 默认监听 0.0.0.0:5000
```

验证：浏览器访问 `http://127.0.0.1:5000/api/health` 返回 `{"code":0,...}` 即成功。

### 2. 前端（开发模式）

```bash
cd frontend
npm install
npm run dev                          # 默认 http://localhost:5173，/api 代理到 :5000
```

### 3. 生产部署（单进程）

```bash
cd frontend && npm install && npm run build   # 产物输出到 frontend/dist
cd ../backend && python app.py                # 后端自动托管 frontend/dist 静态页面
```

访问 `http://127.0.0.1:5000/` 即为完整页面（API 与页面同源）。

### 3.1 子路径部署（重要）

前端**不使用任何绝对路径**：

- Vite 构建配置 `base: './'`：产物 HTML 中 JS/CSS 引用为相对路径（`./assets/...`）；
- API 封装采用相对请求（`fetch('api/...')`）：跟随页面所在目录解析，与页面同前缀。

因此应用可直接部署到任意子路径（如 `https://host/stock-tools/`），只要反向代理把
该前缀下的 `api/` 转发到后端即可：

```nginx
# Nginx 示例：子路径部署
location /stock-tools/ {
    alias /var/www/stock-ossec/frontend/dist/;   # 静态页面（含相对路径资源）
    try_files $uri $uri/ /stock-tools/index.html;
}
location /stock-tools/api/ {
    proxy_pass http://127.0.0.1:5000/api/;       # API 转发到 Flask
    proxy_set_header Host $host;
}
```

> 若部署后页面提示「服务响应异常（非 JSON，疑似返回了 HTML）」或旧版的「响应解析失败」，
> 说明 `api/` 请求未到达 Flask 后端（被静态服务器当成了普通页面/404 处理），请按上述方式
> 配置 API 反向代理，或确认页面与后端同源同前缀。

前端附带子路径部署验证工具（先启动后端 :5000 与 `frontend/subpath-test-server.cjs`
端口 :8899，再执行 `node frontend/subpath-e2e.cjs`）：在 `http://127.0.0.1:8899/app/`
下检查页面、静态资源与 API 是否全部经 `/app/api/` 正常加载。

### 5. 注意事项

- 后端必须在 `backend` 目录下运行，否则会出现模块导入错误。
- 若网页无法打开，先检查后端进程是否在运行，可访问 `http://127.0.0.1:5000/api/health` 验证。
- 关注清单数据存储在浏览器 localStorage 中，清除浏览器数据会丢失关注列表。
- 详情弹窗的 K 线、分时、技术指标、基本面均为真实数据；财务/资金流/评级/暗盘等需专用数据源，暂不展示。
